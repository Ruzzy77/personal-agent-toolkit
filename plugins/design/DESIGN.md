# Design 설계

## 목적과 경계

Design은 제품 화면 설계·구현, 디자인 검토와 사용자 조사에 쓰는 Skill과 공개 참고 자산을
배포한다. 특정 디자인 도구를 대신하거나 사용자 프로젝트의 디자인 시스템보다 자체 취향을
우선하지 않는다.

## 구성과 데이터 정본

- `plugins/design`: Skill, 설명과 배포된 정적 참고 묶음
- `sites/design`: 소유자 전용 탐색·비교 화면과 공개 카탈로그 원본
- `sites/design/designs`: 카탈로그와 asset의 정본

plugin의 참고 묶음은 Site 정본에서 생성한다. 둘을 따로 편집하지 않는다. 제품은 사용자 상태를
저장하지 않으므로 서비스, D1과 R2를 만들지 않는다.

## 공개 표면과 권한

plugin은 MCP 없이 Skill만 제공한다. Site의 WebMCP는 현재 화면의 카탈로그 탐색, 비교와 요청문
준비만 수행하며 저장소 밖의 계정이나 사용자 자료를 수정하지 않는다. 작업 파일 권한은 Design이
아니라 현재 실행 환경과 대상 프로젝트가 정한다.

## 버전과 검증

plugin과 Site는 같은 제품 release version을 사용한다. 카탈로그를 바꾸면 Site 생성 결과와 plugin
export가 같은지 한 번 대조하고 Site build를 확인한다. 시각적 판단이 필요한 화면 변경은 실제
렌더링을 확인하되, 정적 asset마다 의미 없는 snapshot을 추가하지 않는다.
