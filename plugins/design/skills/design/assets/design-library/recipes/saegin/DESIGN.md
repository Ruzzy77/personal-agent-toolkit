# 색인 디자인 원칙

## 성격

색인은 디지털 아카이브의 표지 목록에서 한 권을 고른 뒤 긴 내용을 읽는 화면에
사용한다. 짙은 코발트는 전체 배경에, 네온 노란색은 홈 링크, 읽기 설정과 절
표시에 사용한다.

## 쓰임

디지털 아카이브의 긴 발간물, 조사 기록과 연구 내용을 읽는 화면에 사용한다.
홍보 중심 내용, 장식 중심 내용과 단계가 많은 작업 화면에는 다른 디자인이 더
잘 맞는다. 긴 글이라도 밝은 지면이 필요하면 서책을 사용한다.

## 구성

- 화면 위 양쪽에는 `LIBRARY` 홈 링크와 읽기 설정만 둔다.
- 도입부는 좁은 발간 정보 영역과 넓은 제목 영역으로 나눈다.
- 본문은 제목 영역의 왼쪽 선에 맞춰 한 열로 배치한다.
- 제목 영역에서는 제목을 먼저 두고 도입문을 그 아래에 배치한다. 두 요소를 가로로 나누지 않는다.
- 발간 유형, 날짜와 호수는 발간 정보 영역에 모으고 제목 주변에 되풀이하지 않는다.
- 발간 정보는 두 행으로 고정한다. 첫 행에는 유형·Digest 호수·예약 시각을, 둘째 행에는 `DD MON YYYY` 날짜만 둔다.
- 예약 시각은 발간호 ID에 시각 구분값이 있을 때만 표시하며 저장 시각이나 날짜 행에 되풀이하지 않는다.
- 제목은 배경, 테두리와 별도 상자 없이 제목 영역에 직접 둔다.
- 820px 아래에서는 발간 정보를 제목 위로 옮기고 모든 내용을 한 열로 배치한다.

## 글자

본문, 제목과 조작에는 시스템 산세리프를 사용한다. 제목은 740–820 굵기, 본문은
400–470 굵기를 기본으로 한다. 세리프는 짧은 인용과 도판 표제를 본문과 구분할
때만 사용한다. 첫 글자를 확대하는 장식은 쓰지 않는다.

## 색

| 역할 | 화면 | 인쇄 | 사용 |
|---|---|---|---|
| `--paper` | #081747 | #FFFFFF | 전체 바탕 |
| `--surface` | #0C1D54 | #F4F4EF | 표와 인용의 면 |
| `--ink` | #F4F2E9 | #111111 | 제목과 본문 |
| `--soft` | #B2BCDA | #444444 | 날짜와 보조 설명 |
| `--accent` | #C9ED12 | #56650A | 버튼, 표식과 표 머리 |
| `--accent-ink` | #081747 | #FFFFFF | 강조 상자 위의 글자와 아이콘 |

네온 노란색 위에는 코발트 글자만 놓는다. 링크는 밑줄이나 형태를 함께 사용해
색만으로 구분하지 않는다. 인쇄에서는 지면을 밝은 값으로 뒤집고 네온 표식은
흰 종이에서 읽히는 짙은 올리브로 바꾼다.

## 공통 요소

- **LIBRARY 홈 링크:** 높이 42px 이상의 네온 직사각형. 화살표나 ‘서가’ 문구를 붙이지 않는다.
- **읽기 설정:** 같은 높이의 네온 버튼을 붙여 배치한다. 비활성 상태에서도 글자와 윤곽이 읽혀야 한다.
- **구조 표식:** 절 제목 앞의 작은 네온 사각형과 발간 정보 영역 위의 짧은 막대만 사용한다.
- **강조 상자:** 네온 왼쪽 선과 단색 배경을 함께 사용하며 둥근 모서리와 그림자는 쓰지 않는다.
- **상태와 점검:** 진행 상태, 재확인 조건과 짧은 판정도 별도 색상 상자를 만들지 않고 강조 상자를 재사용한다.
- **문장 강조와 수치:** 문장 안의 주요 판단은 `.reader-key-sentence`, 줄바꿈되면 의미가 끊기는 수치 묶음은 `.num`을 사용한다.
- **표:** 머리행에는 네온 배경을 사용하고 본문 행은 한 겹의 선으로 나눈다.

## 상태

- hover: 네온 배경을 `--accent-hover`로 바꾸고 위치나 크기는 움직이지 않는다.
- press: 네온 배경의 밝기를 낮추되 레이아웃은 움직이지 않는다.
- focus: 2px 윤곽과 3px 간격을 사용한다.
- selected: 코발트 배경, 네온 글자와 네온 윤곽을 함께 사용한다.
- disabled: 불투명도를 낮추고 조작을 막지만 라벨은 읽을 수 있게 둔다.

## 이미지와 도식

이미지는 본문 폭을 기본으로 하며 읽기 순서를 끊을 만한 장식 이미지는 넣지 않는다.
도식과 표가 본문 폭보다 넓으면 해당 영역 안에서만 가로 스크롤한다. 캡션은 이미지
아래에 두고 본문보다 한 단계 작은 산세리프로 쓴다.
