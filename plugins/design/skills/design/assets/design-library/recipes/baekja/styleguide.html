백자 디자인

백자는 항목을 빠르게 훑고 선택하거나 값을 바꾸는 갤러리, 허브와 작업 도구에 사용한다. 세부 원칙은 백자 디자인 원칙에서 확인할 수 있다. 카드에 마우스를 올리면 상단 광택 애니메이션이 한 번 실행된다.

주의 — 저장 공간

상태는 색과 라벨을 함께 사용해 구분한다.

백자의 .callout은 음각 배경을 사용하며 테두리와 강조색은 두지 않는다.

모션

상태 변화는 --t-fast 140ms, 카드 상승은 --t-base 220ms, 등장은 --t-slow 420ms를 쓴다. transform과 opacity만 움직이며, 등장은 페이지를 열 때 한 번만 실행한다. prefers-reduced-motion이면 모든 움직임을 끈다.

HTML 틀 활용

카드·목록·수치 영역이 필요한 화면에서는 아래 틀을 복사해 쓸 수 있다. 필요 없는 구획은 빼고 순서는 화면의 내용에 맞게 바꾼다.

cp designs/baekja/templates/artifact.html work-products/새-화면.html
python designs/tools/bundle.py --inject work-products/새-화면.html
python designs/tools/bundle.py --check work-products/새-화면.html

구성요소의 쓰임은 백자 디자인 원칙에서 볼 수 있다.
