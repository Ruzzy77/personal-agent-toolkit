# Manage the environment

Separate the host's configuration, installed distribution, tools exposed to this task, and the remote canonical content. Use the current supported interface for each; an installed package does not establish authentication or successful use.

Read only the reference matching the request:

- [Host connection](references/host-connection.md): connect or update the private canonical base document, inspect its managed projection, or complete a staged local Skill migration.
- [Connected plugins](references/connected-plugins.md): inspect a named plugin's installation, dependencies or permissions and carry out a requested supported change.
- [OpenAI and the workbench](references/openai.md): local Codex settings, official OpenAI facts, model or prompt changes, and user-requested instruction browsing or editing.

Public source discovery, including Exa, belongs to `investigate-corpus`'s conditional public-search reference. It does not require environment maintenance first.

Toolkit distributes connection methods, not the user's base text or a permanent machine-path map. Resolve project Workspaces through the exposed Corpus Workspace tools and the current host registration. Keep ordinary guidance retrieval independent of the workbench and of installation or update operations.
