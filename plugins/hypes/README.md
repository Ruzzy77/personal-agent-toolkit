# Hypes

Hypes는 여러 AI가 소유자 인증을 거쳐 공유하는 비공개 사용자 관계 모델이다. 저장된 관계는 후속 요청의 해석과 선택에 활용하며, 현재
사용자의 말이 우선한다. Sense는 범용 지침을, Corpus는 출처 기반 지식을, 대화 시스템은 대화
기록을 관리한다.

## 활용

Hypes의 저장 관계는 해석·설명·질문·선택에 반영한다. 재사용 관계는 상호작용에 따라 갱신한다.
관계없는 조회와 단순 변환은 현재 입력으로 수행한다.

에이전트는 관계를 추가·수정·삭제한다. 저장 관계는 가변적 해석이다.

## 인식론적 조정

사용자의 친숙도·이해·적용·전이·채택은 설명과 선택에 필요할 때 서로 다른 관계로 표현할 수 있다.
이 관계는 지식의 인증이나 고정 등급이 아니라 현재 상호작용을 조정하는 잠정적 해석이다.

프로젝트 파일과 공동 산출물은 사용자 지식 수준 추정에서 제외한다. 현재 대화에서 드러난 수준을
설명의 시작점·용어·진행 폭에 반영하고, 사용자의 미이해나 교정이 나타나면 관계를 수정한다. 이를
위해 출처 연결이나 별도의 자료 이력을 요구하지 않는다.

## 관계 모델

- **Node**: 에이전트가 구분한 개념
- **Predicate**: 관계 유형
- **Edge**: 두 Node를 Predicate로 연결한 관계

이름과 관계 유형은 에이전트가 현재 이해에 맞게 구성한다. 새 정보는 기존 구조의 교체나 삭제로
반영한다.

## MCP 도구

`hypes_read`는 이름·별칭·설명 또는 기존 참조에서 시작해 관련 그래프 조각을 반환한다.
시작점이 없으면 이름순 목차를 보여 주며, `continuation`은 전체 모델 검토를 이어 간다. 읽기
연결은 현재 스키마를 조회한다.

`hypes_rewrite`는 `put_node`, `put_predicate`, `put_edge`, `delete` 연산을 한 저장 트랜잭션으로
적용한다. 어느 연산이든 실패하면 전체 patch를 되돌린다. Node나 Predicate를 삭제하면 연결된
Edge도 같은 트랜잭션에서 함께 삭제하며 결과에 그 수를 포함한다.

## 저장 경계

Hypes는 이후 상호작용에 재사용할 비민감 관계를 소유자별 원격 저장층에 보관한다. 원 대화와
답변 전문은 대화 시스템에, 프로젝트 정보는 프로젝트에, 출처는 Corpus에, 장기 지침은 Sense에
귀속된다.

OpenAI에서는 Hypes Skill을 `Personal Agent Toolkit` 통합 plugin에 포함하고, Claude의 Hypes
plugin은 다음 상시 원격 MCP를 직접 선언한다. 로컬 MCP server나 공개 터널은 요구하지 않는다.

```text
https://personal-agent-context.hiyaq77.workers.dev/hypes/mcp
```

Codex, Claude Code, Claude Desktop/Cowork, claude.ai와 ChatGPT는 같은 관계 graph를 읽고
원자적으로 고친다.

로컬 SQLite 구현과 최초 이관 도구는
[`engines/hypes`](../../engines/hypes/README.md)에 있습니다. 설치 plugin에는 이를 포함하지 않으며,
로컬 자료는 원격 정본과 자동으로 동기화되지 않습니다.
