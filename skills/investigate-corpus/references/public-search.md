# Public source discovery

Use connected Exa search when requested or when semantic source discovery fits the question. Discover the currently exposed search and fetch tools and follow their schemas; historical parameter names, category syntax, Boolean operators and date filters are not proof of present support.

Describe the desired page or evidence concretely. Let the purpose and requested scope determine search depth rather than a fixed number of queries. Distinct searches should explore materially different questions or source areas. Fetch selected pages when their snippets do not establish the needed claim; verify numbers, quotations, dates and claim scope in the original source.

When time matters, distinguish publication date from the event date in the requested timezone. Search candidates, read excerpts and fully inspected sources are different evidence states. If reporting a review count, count the unique sources actually inspected, not requested result counts, retries or duplicate URLs.

On a missing connection or failed request, distinguish unavailable tools, authentication and request limits. Use another suitable search or reading tool unless the user restricted the provider. Follow the current task's source restrictions. Do not create a results directory or prescribe a report format merely because search was performed; link sources near the claims they support.
