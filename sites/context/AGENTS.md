# Workspace Site

- Toolkit의 `sites/context/`가 소스 정본이며 기존 private Site가 배포 대상입니다. 상세 경계와 저장 계약은 README를 따릅니다.
- Sense·Corpus의 기존 서비스와 저장층을 사용합니다. 별도 DB, Resolver나 사용자 인증 서비스를 만들지 않습니다.
- 화면의 저장 조작과 요청받은 에이전트 저장은 같은 소유자·버전 검사 및 재조회 경로로 이어집니다. 저장됨과 현재 실행 적용은 구분합니다.
- 표시 문구는 콘텐츠와 필요한 구조·대상·복구 상태로 한정합니다. 기능 설명과 내부 절차를 기본 화면에 노출하지 않습니다.
- 과거 Resolver fixture의 사용자 변경은 보존하며 실행에 연결하지 않습니다. 개인 지침 전문, 복구 자료와 runtime 비밀은 소스·배포 archive에 포함하지 않습니다.
