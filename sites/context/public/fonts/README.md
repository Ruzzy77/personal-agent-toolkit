# Library webfonts

## Noto Serif KR

`NotoSerifKR-Bold-korean.woff2` is the Korean webfont for Noto Serif KR Bold.

- Source package: https://www.npmjs.com/package/@fontsource/noto-serif-kr
- Specimen: https://fonts.google.com/noto/specimen/Noto+Serif+KR
- License: `OFL-Noto-Serif-KR.txt`

The font is used for Library issue titles.

## Noto Sans KR

`NotoSansKR-Regular-korean.woff2` and `NotoSansKR-Bold-korean.woff2` are the Korean webfonts for Noto Sans KR Regular and Bold.

- Source package: https://www.npmjs.com/package/@fontsource/noto-sans-kr
- Specimen: https://fonts.google.com/noto/specimen/Noto+Sans+KR
- License: `OFL-Noto-Sans-KR.txt`

The font is used for Library reader body copy and text headings.

## Barlow Condensed

`BarlowCondensed-SemiBold-latin.woff2` is the Latin webfont for Barlow Condensed SemiBold by Jeremy Tribby.

- Original font: https://github.com/jpt/barlow
- Specimen: https://fonts.google.com/specimen/Barlow+Condensed
- License: `OFL-Barlow.txt`

The font is used for Library metadata and other short decorative labels.

## Library Brush

`LibraryBrush-2.2-Regular.woff2` and `.ttf` form a custom display font built from the Library wordmark and newly generated glyph sources. Version 2.2 contains A–Z, a–z, 0–9, ampersand, apostrophe, period, colon, middle dot, hyphen, slash, plus, exclamation mark, and question mark. Every generated source keeps transparent padding around each glyph. Narrow row strips and single-glyph overrides prevent adjacent cells from clipping or merging. Wordmark crops retain only their intended connected component so neighboring strokes cannot enter a glyph. Individual optical weight corrections bring uppercase, lowercase, and digit strokes into consistent ranges without scaling their proportions. Uppercase, x-height, ascender, descender, baseline, and round-letter overshoot metrics are normalized in the font builder. The versioned filename ensures each revised font is loaded instead of a cached earlier build.

The font is used for the Library wordmark, issue metadata, and other short decorative labels. The original PNG remains the source reference.
