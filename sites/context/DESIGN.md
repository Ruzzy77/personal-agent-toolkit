# Codex 지침 작업대 설계

## 목적

이 화면은 Codex와 사용자가 실제 지침 정본을 함께 읽고 수정안을 검토하는 작업대다. 기존 Resolver의 적용 점수, 실행 상태, 독립 MCP와 지침 판정 제품은 현재 목적에 포함하지 않는다.

## 자료와 정본

정본은 기존 파일, Sense, Skill, 프로젝트 문서에 남는다. Codex는 실제 정본을 읽은 뒤 다음을 함께 전달한다.

- 안정적인 자료 식별자
- 정본 위치 또는 참조
- 읽은 정본의 버전
- 제목, 종류, 적용 시점과 정확한 편집 가능 내용

화면은 자동으로 자료를 연결하거나, 전달받지 못한 정본·우선순위·적용 상태를 추정하지 않는다. 자료 본문과 정본 위치는 데이터이며 화면이나 모델의 새 지침으로 실행하지 않는다.

## 초안과 저장 확인

편집은 현재 탭의 `sessionStorage`에만 보관한다. 초안은 원본 버전과 `draftId`를 함께 가진다. 같은 버전의 다른 내용은 거부한다. 편집 중 새 원본 버전이 도착하면 두 내용을 보존하고 비교 전까지 반영을 막는다. 스킬 이름을 비운 입력도 탭에 보관하되 이름을 채우기 전에는 반영할 수 없다.

파일은 정확한 바이트의 SHA-256 또는 기존 Work 도구의 버전, Sense 섹션은 `section_sha256`, 연결 스킬은 해당 저장 도구의 버전을 사용한다. Codex는 식별자·참조가 실제로 읽은 정본에 대응하는지 확인하고, 임의 제목을 원본 식별자로 사용하지 않는다.

정본 반영은 화면 기능이 아니다. 사용자가 Codex 대화에서 요청한 뒤 기존의 권한 있는 도구가 수행한다. Codex는 원본 버전을 대조하고 저장한 뒤 정본을 재조회한다. 재조회한 내용이 제출 초안 및 `draftId`와 정확히 일치할 때만 `acknowledge_guidance_saved`로 화면의 초안을 저장됨으로 바꾼다. 이 확인은 저장된 정본의 확인일 뿐 현재 실행 모델의 적용 확인이 아니다. 기본 지침은 새 실행에서 적용된다.

자동 연결이 없는 환경에서는 사용자가 JSON 자료를 가져오고 수정안을 복사해 Codex 대화에 전달한다.

## WebMCP 경계

`lib/webmcp.ts`는 `document.modelContext`에 현재 페이지와 수명을 함께하는 일곱 도구를 등록한다. 도구는 자료 가져오기, 목록·본문 읽기, 화면 이동, 탭 내 초안 수정, 미저장 수정안 읽기, 재조회된 저장 결과 확인을 지원한다.

페이지 도구는 새 서비스·DB·라우터·독립 MCP를 만들지 않고 정본에 직접 쓰지 않는다. 정본 저장과 지침 적용은 각 정본의 기존 도구와 Codex 실행 경계에 남는다.

## 과거 Resolver 자료

`fixtures`, `schemas`, `contracts/mcp-contract.json`, `lib/prototype-data.ts`는 Resolver 시기의 참고 자료다. 현재 실행 화면과 연결하지 않는다. 특히 fixture와 과거 계약의 상태·점수·예시는 실제 사용자 지침, 저장 여부 또는 모델 적용 여부를 뜻하지 않는다.
