# 서책(Seochaek)

긴 내용을 차분하게 읽고 원하는 부분을 찾기 쉽게 하는 디자인이다. 좁은 읽기
폭, 명조 본문과 단순한 목차를 사용한다.

- [미리보기](index.html)
- [형식별 규칙](formats.json)
- [HTML 틀](/templates/seochaek/templates/book.html)
- [디자인 원칙](DESIGN.md)

## 원칙

1. 책상, 책등, 종이 그림자처럼 읽기에 필요하지 않은 연출은 사용하지 않는다.
2. 본문은 좁은 읽기 폭과 충분한 줄 간격을 유지한다.
3. 목차와 제목은 내용을 찾는 데 필요한 이름과 번호만 보여 준다.
4. 상자와 구분 기호는 내용에 실제 경계나 순서가 있을 때만 사용한다.
5. 형식이 달라져도 명조 본문과 차분한 여백을 유지한다.

## 형식

문서와 긴 웹 글에는 좁은 한 열을 사용한다. 슬라이드는 짧은 문장과 장 제목을
중심으로 구성하고, 이미지는 제목이나 짧은 문장 하나에 집중한다. 자세한
판면과 글자 크기는 [formats.json](formats.json)에 적혀 있다.

## 파일

| 파일 | 내용 |
|---|---|
| `tokens.css` | 색, 서체, 본문 폭과 간격 |
| `base.css` | 제목, 본문, 목록, 표와 인쇄 |
| `book.css` | 표지, 목차, 장, 절, 예시와 각주 |
| `formats.json` | 웹·앱, 문서, 슬라이드와 이미지 규칙 |

## 주요 클래스

- 문서: `.page`, `.cover`, `.chapter`, `.sub`, `.prose`
- 목차: `.toc`, `.toc-no`, `.toc-title`, `.toc-page`
- 보조 내용: `.example`, `.callout`, `.maxim`, `blockquote.key`
- 목록과 표: `ol.steps`, `ul.plain`, `.table-wrap`
- 끝부분: `.footnotes`, `.colophon-book`, `.docfoot`
