색인 디자인

긴 발간물에서는 현재 위치와 이동 경로를 분명히 표시한다. 홈 링크, 발간 정보와 읽기 설정에만 네온색을 사용한다.

판면과 읽기 열

넓은 화면의 도입부는 발간 정보 영역과 제목 영역으로 나눈다. 본문은 제목의 시작선에 맞춰 한 열로 배치한다. 작은 화면에서는 발간 정보를 제목 위로 옮기고 같은 읽기 순서를 유지한다.

화면 위 양쪽에는 홈 링크와 읽기 설정만 둔다. 본문을 읽는 동안에도 접근할 수 있지만 내용의 폭이나 줄 길이를 바꾸지는 않는다.

색

코발트는 아카이브 배경에, 네온 노란색은 조작 요소와 구조 표시에 사용한다. 네온 배경에는 코발트색 글자를 사용하며 본문에 네온색 글자를 직접 쓰지 않는다.

본문에는 시스템 산세리프를 사용한다. 굵기와 크기로 위계를 구분하고 첫 글자 장식은 쓰지 않는다. 세리프는 짧은 인용을 본문과 구분할 때만 사용한다.

짧은 인용 한 문장에만 세리프를 사용한다.

조작 상태

조작 요소에는 네온 배경과 코발트 라벨을 사용한다. 선택 상태에는 코발트 배경과 네온 글자를 사용하며, 비활성 상태에서도 라벨을 표시한다.

네온색은 홈 링크, 읽기 설정, 절 머리와 필수 강조에만 사용한다.

.callout, .finding, .conclusion과 .maxim은 같은 강조 상자 형식을 사용한다. .maxim만 세리프로 표시한다.
