# 색인(Saegin)

짙은 코발트 판면과 네온 노란색 표식을 사용하는 장문 발간물 디자인이다. 홈 링크와
발간 정보는 별도 영역에 두고 제목과 본문은 한 열로 배치한다.

- [미리보기](styleguide.html)
- [형식별 규칙](formats.json)
- [HTML 틀](/templates/saegin/templates/reader.html)
- [디자인 원칙](DESIGN.md)

## 원칙

1. 제목과 본문은 산세리프를 기본으로 하고 세리프는 인용처럼 제한된 장식에만 쓴다.
2. 네온 노란색은 조작, 위치와 구조를 드러내는 표식에만 사용한다.
3. 도입부는 발간 정보 영역과 제목 영역으로 나누고 본문은 제목의 시작선에 맞춘다.
4. 각진 면과 한 겹의 선을 사용하며 그림자, 그라데이션과 겹테두리를 쓰지 않는다.
5. 작은 화면과 인쇄에서는 발간 정보를 제목 위로 옮겨 한 개의 읽기 열로 바꾼다.

## 형식

웹에서는 `LIBRARY` 홈 링크와 글자 크기 컨트롤을 고정한다. 문서에서는
이 컨트롤을 빼고 발간 정보를 첫 페이지 위쪽에 둔다. 슬라이드와 이미지는 코발트
판면, 네온 표식과 한 개의 주요 대상만 사용한다. 구체적인 판면과 글자 크기는
[formats.json](formats.json)을 따른다.

## 파일

| 파일 | 내용 |
|---|---|
| `tokens.css` | 색, 글자, 읽기 폭과 간격 |
| `base.css` | 본문, 표, 포커스, 다크 모드와 인쇄 |
| `reader.css` | 홈 링크, 읽기 설정, 발간 정보 영역과 본문 구성 |
| `formats.json` | 웹, 문서, 슬라이드와 이미지 규칙 |

## 주요 클래스

- 판면: `.reader-document`, `.reader-opening`, `.reader-content`
- 도입부: `.reader-meta`, `.reader-header`
- 이동과 설정: `[data-library-return]`, `.reader-tools`
- 내용: `.reader-section`, `.reader-callout`, `.reader-key-sentence`, `.num`, `.table-scroll`, `.reader-quote`
