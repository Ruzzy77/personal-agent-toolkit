# 거푸집 디자인 원칙

## 성격

거푸집은 회색 작업면과 패널, 청사진 파랑과 주황 강조색을 사용한다. 수치는
구획된 칸에 정렬하고 구성 요소 사이의 관계와 작업 순서는 연결선으로 표시한다.
문서 사이트에서는 구조물과 인쇄 문서가 서로 다른 높이에 놓인 것처럼 보이게
한다.

## 쓰임

기술 설명, 구성 안내, 단계와 연결 관계를 보여 주는 내용과 여러 기술 문서를
함께 제공하는 문서 사이트에 사용한다. 긴 본문 읽기에는 서책을, 자료와 그래프가
중심인 내용에는 한지를, 조작이 중심인 화면에는 백자를 사용한다.

## 구성

- 기본 판면은 최대 폭 960px의 한 열이다.
- 문서는 제목, 구성과 절차 순서로 배치한다.
- 문서 사이트는 상위 셸 아래에 A4 페이지 묶음을 연속 배치한다.
- 슬라이드는 큰 구획 번호와 한 개의 도식 또는 표를 사용한다.
- 이미지는 한 개의 구조나 연결 관계에 집중한다.
- 제목 정보, 구획 번호와 배지는 실제 내용에 필요할 때만 사용한다.

## 문서 사이트 셸

- 상단 셸은 브랜드, 상위 메뉴와 도구의 세 영역으로 나눈다. 도구의 내용이
  달라져도 각 영역의 폭은 유지한다.
- 같은 영역의 다른 문서로 이동하는 메뉴와 현재 문서 안에서 이동하는 목차를
  별도 구획으로 제공한다. 두 종류의 링크를 한 줄에 섞지 않는다.
- 현재 선택한 상위 메뉴는 파랑 채움, 같은 구조 안의 보조 선택은 옅은 파랑
  바탕과 파랑 하단선으로 표시한다.
- 좁은 화면에서는 첫 줄에 브랜드, 현재 영역·문서명과 도구를 놓고, 둘째 줄에
  상위 메뉴를 모두 표시한다. 390px 화면에서도 여섯 항목을 숨기지 않는다.
- 문서 전환 메뉴와 목차가 길어지면 각 구획 안에서만 가로로 움직이게 한다.

## 선과 높이

- 하나로 붙은 모듈은 2px 외곽선과 1px 내부 이음을 공유한다. 각 카드에 별도
  테두리를 둘러 겹치는 선을 만들지 않는다.
- 사이트 셸, 페이지 이동기와 독립된 조작 패널에는 오른쪽 아래로 밀린 단색
  그림자를 사용한다.
- A4 문서지는 작업면 위에 놓인 종이이므로 넓고 부드러운 확산 그림자를 사용한다.
  구조물 그림자를 문서지에 사용하거나 종이 그림자를 메뉴에 사용하지 않는다.

## 글자

산세리프 하나를 사용한다. 제목은 700–800 굵기, 본문은 400 굵기를 기본으로
한다. 수치에는 tabular-nums를 사용하고 짧은 라벨은 넓은 자간으로 구분한다.
형식별 크기는 [formats.json](formats.json)을 따른다.

## 색

| 역할 | 밝은 배경 | 어두운 배경 | 사용 |
|---|---|---|---|
| `--paper` | #e8e8e5 | #16171a | 전체 바탕 |
| `--paper-raised` | #f3f3f0 | #1f2125 | 내용 패널 |
| `--work-surface` | #d6d6d1 | #101114 | 문서 사이트 작업면 |
| `--sheet` | #f5f5f2 | #1f2125 | A4 문서지 |
| `--ink` | #1d1f22 | #e9eae6 | 제목과 본문 |
| `--blue` | #1a4fc0 | #7da2ff | 구조, 연결과 링크 |
| `--orange` | #b54e00 | #ff9553 | 주의와 한 곳의 강조 |
| `--bp-bg` | #16357e | #10275e | 선형 도식의 배경 |

파랑과 주황을 같은 요소에서 함께 강조하지 않는다. 상태는 색만으로 구분하지
않고 문구와 선 모양을 함께 쓴다.

## 표와 도식

- 표에는 열 이름과 단위를 적고 숫자를 오른쪽으로 정렬한다.
- 도식은 균일한 선, 간단한 기하 형태와 짧은 라벨을 사용한다.
- 이미지 안의 설명은 최소화하고 자세한 내용은 캡션으로 분리한다.
- 넓은 표와 도식은 웹·앱에서 해당 영역 안에서만 가로로 움직이게 한다.
- 표와 연결형 모듈의 외곽은 2px, 내부 구분은 1px을 기본으로 한다.

## 이미지

회색 또는 짙은 파랑 바탕 가운데 하나를 사용한다. 선형 도식은 밝은 청백색
선으로 그리고, 주황은 주의가 필요한 한 지점에만 사용한다. 사실적인 인물,
과도한 그라데이션, 로고와 긴 문장은 넣지 않는다.
