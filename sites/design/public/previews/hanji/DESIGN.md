# 한지 디자인 원칙

## 성격

한지는 따뜻한 바탕, 산세리프 활자와 가는 구분선을 사용한다. 요약을 먼저 두고
자료와 설명을 이어 배치하며, 글자 굵기와 간격으로 각 단계의 위계를 구분한다.

## 쓰임

요약 문서, 자료 설명과 시각 설명에 사용한다. 항목과 조작이 많은 화면에는
백자를, 긴 글에는 서책을 사용한다. 표와 그래프가 중심인 내용에는 한지를
우선한다.

## 구성

- 기본 판면은 최대 폭 980px의 한 열이며 본문 측정폭은 680px이다.
- 문서는 제목, 요약 값, 자료와 설명 순서로 배치한다.
- 구획은 가는 가로선 하나로 나누고 상자를 겹치지 않는다.
- 슬라이드는 한 개의 요약 값이나 그래프에 집중한다.
- 관계 그림과 그래프는 이미지 애셋으로 두고 밝은 배경과 어두운 배경 판을
  함께 준비한다.

## 글자

산세리프 하나를 사용한다. 제목은 720–780 굵기, 본문은 400 굵기를 기본으로
한다. 큰 제목은 자간을 좁히고 수치에는 tabular-nums를 사용한다. 형식별
크기는 [formats.json](formats.json)을 따른다.

## 색

| 역할 | 밝은 배경 | 어두운 배경 | 사용 |
|---|---|---|---|
| `--paper` | #f3efe5 | #191814 | 전체 바탕 |
| `--paper-raised` | #faf7f0 | #211f1a | 코드와 올린 면 |
| `--ink` | #1c1c18 | #eee9df | 제목과 본문 |
| `--soft` | #625e55 | #aaa397 | 라벨과 보조 설명 |
| `--accent` | #a23e28 | #e1785f | 콜아웃 선과 핵심 강조 |
| `--link` | #275d6b | #82b5c0 | 링크 |

어두운 배경은 시스템 설정을 기본으로 따르고 `data-theme`이 항상 이긴다.
상태는 색만으로 구분하지 않고 라벨 문구를 함께 쓴다.

## 표와 그래프

- 표 머리에는 굵은 가로선을 긋고 열 이름과 단위를 적는다.
- 숫자는 오른쪽으로 정렬하고 tabular-nums를 사용한다.
- 그래프 계열은 `--chart-1`부터 순서대로 쓰고 색 외에 라벨로도 구분한다.
- 순차 자료에는 `--seq-100`부터의 단계 색을 사용한다.
- 넓은 표와 그래프는 해당 영역 안에서만 가로로 움직이게 한다.

## 이미지

따뜻한 중립색 바탕에 한 개의 자료나 관계 그림을 담는다. 종이 질감, 낙관과
장식용 꼬리표는 넣지 않고, 설명은 이미지 아래 캡션으로 분리한다.
