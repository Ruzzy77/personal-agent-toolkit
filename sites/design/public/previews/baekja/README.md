# 백자(Baekja)

밝은 중립색, 절제된 파랑과 매끈한 표면을 사용하는 디자인이다. 여러 항목을
빠르게 훑고 선택하거나 한 개의 대상을 선명하게 보여 주는 데 어울린다.

- [미리보기](styleguide.html)
- [형식별 규칙](formats.json)
- [HTML 틀](/templates/baekja/templates/artifact.html)
- [디자인 원칙](DESIGN.md)

## 원칙

1. 산세리프 하나를 사용하고 크기, 굵기와 여백으로 순서를 만든다.
2. 파랑은 링크, 선택이나 핵심 강조 한 곳에만 사용한다.
3. 카드와 표면에는 얕은 깊이만 주고 장식 효과를 반복하지 않는다.
4. 문서와 인쇄에서는 반투명 효과와 움직임을 제거한다.
5. 슬라이드와 이미지는 한 개의 주요 대상에 집중한다.

## 형식

웹·앱은 목록, 카드와 조작 상태를 중심으로 구성한다. 문서는 제목, 요약과 항목
목록 순서로 단순화한다. 슬라이드와 이미지는 큰 제목, 한 개의 화면이나 대상을
사용한다. 판면과 글자 크기는 [formats.json](formats.json)을 따른다.

## 파일

| 파일 | 내용 |
|---|---|
| `tokens.css` | 색, 표면, 서체, 크기와 움직임 |
| `base.css` | 본문, 표, 포커스와 인쇄 |
| `ui.css` | 카드, 목록, 버튼, 선택과 입력 |
| `formats.json` | 웹·앱, 문서, 슬라이드와 이미지 규칙 |

## 주요 클래스

- 판면: `main`, `.frame`, `.bar`, `.hero`, `.section`, `.footnote`
- 표면: `.card`, `.card-grid`, `.list`, `.row`, `.stat-row`, `.stat`, `.callout`
- 컨트롤: `.btn`, `.seg`, `.field`, `.chip`
- 상태 텍스트: `.status-good`, `.status-warn`, `.status-bad`
- 움직임: `.reveal`
