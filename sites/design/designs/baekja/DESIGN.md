# 백자 디자인 원칙

## 성격

백자는 밝은 중립색, 매끈한 표면과 절제된 파랑을 사용한다. 여백으로 정보 위계를
구분하고 카드 상단의 옅은 내부선 하나만 표면 효과로 사용한다.

## 쓰임

여러 항목을 빠르게 훑고 선택하는 내용이나 한 개의 대상을 선명하게 보여 주는
내용에 사용한다. 긴 글이나 표와 그래프가 많은 내용에는 다른 디자인이 더 잘
맞는다.

## 구성

- 웹·앱은 최대 폭 980px의 한 열을 기본으로 하며 카드나 목록 가운데 필요한
  한 가지 방식을 고른다.
- 문서는 제목, 요약과 항목 목록 순서로 단순화한다.
- 슬라이드와 이미지는 한 개의 주요 대상에 집중한다.
- 내용이 길어지면 서책을, 자료 설명이 많아지면 한지를 검토한다.

## 글자

산세리프 하나를 사용한다. 제목은 600–700 굵기, 본문은 400 굵기를 기본으로
한다. 큰 글자는 자간을 약간 좁히고, 숫자를 나란히 놓는 곳에는 tabular-nums를
사용한다. 형식별 크기는 [formats.json](formats.json)을 따른다.

## 색

| 역할 | 밝은 배경 | 어두운 배경 | 사용 |
|---|---|---|---|
| `--paper` | #f5f5f7 | #0d0d0f | 전체 바탕 |
| `--paper-raised` | #ffffff | #1c1c1e | 카드와 목록 표면 |
| `--ink` | #1d1d1f | #f5f5f7 | 제목과 본문 |
| `--soft` | #6e6e73 | #a1a1a6 | 설명 |
| `--accent` | #0066cc | #409cff | 링크, 선택과 핵심 강조 |

파랑은 한 화면이나 한 페이지에서 필요한 한 곳에만 사용한다. 색만으로
상태를 구분하지 않고 문구와 형태를 함께 쓴다.

## 상태와 움직임

- hover: 항목의 배경을 바꾸거나 카드를 2px 올린다.
- press: 버튼을 0.97 배율로 줄인다.
- focus: 2px 파랑 테두리를 바깥쪽에 표시한다.
- selected: 선택된 표면과 문구를 함께 바꾼다.
- disabled: 투명도와 조작 가능 여부를 함께 바꾼다.
- `prefers-reduced-motion`이면 움직임을 끈다.
- 문서, 슬라이드와 이미지에는 hover, blur와 등장 움직임을 적용하지 않는다.

## 이미지

밝은 중립색 바탕, 한 개의 선명한 대상과 얕은 깊이를 사용한다. 파랑은 한 곳의
초점에만 사용하며, 작은 UI 글자나 여러 장식 요소를 이미지에 넣지 않는다.
